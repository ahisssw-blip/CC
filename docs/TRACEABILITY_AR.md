# مصفوفة تتبع المواصفات العربية

هذه المصفوفة تربط كل مطلب من ملف `bb.txt` بوحدة تنفيذ واختبار. لا يُغلق المطلب إلا بعد اختبار وظيفي واضح.

| المجال | المطلب التفصيلي | الوحدة المستهدفة | الحالة |
|---|---|---|---|
| الاتصال | API_ID وAPI_HASH وتسجيل الدخول بالهاتف والرمز و2FA | `telegram_gateway.py`, `session_runtime.py` | منفذ أساسيًا |
| القنوات | عرض القنوات العشر في واجهة واحدة | واجهة القنوات + مزامنة | قيد التنفيذ |
| الأرشيف | آلاف المنشورات مع فهرسة محلية | `studio_store.py`, `telegram_sync.py` | منفذ جزئيًا |
| التحرير | النص مع الحفاظ على Entities | محرر النص | قيد التنفيذ |
| الوسائط | الصور والفيديو والملفات والألبومات | `message_model.py` | نموذج محلي مع تحقق |
| الأزرار | إضافة وحذف وتعديل الأزرار والروابط | `message_model.py` | نموذج محلي مع تحقق |
| النقل | نقل المنشور إلى قناة أخرى | `repost_queue.py` | خطة آمنة بانتظار التنفيذ |
| الجدولة | إعادة نشر مجدولة مع فواصل وإعادة محاولة | `repost_queue.py` + مدير الحزم | مخطط التنفيذ |
| التنظيم | الوسوم الداخلية وربط المنشورات | طبقة metadata | مخطط |
| النسخ | قبل/بعد وسجل Undo واستعادة | سجل الإصدارات | منفذ جزئيًا |
| التحديد | تعديل عشرات أو مئات المنشورات دفعة واحدة | حزم التغييرات | منفذ جزئيًا |
| العرض | شريط القنوات والمنشورات ولوحة جانبية RTL | `ui/` | منفذ أوليًا |
| الفلاتر | قناة، تاريخ، نطاق، نوع، رابط، هاشتاغ | خدمة البحث | منفذ جزئيًا |
| الفلاتر | مشاهدات وتفاعلات وتعديل وأخطاء وتكرار وأداء ضعيف | `advanced_filters.py` | منفذ أوليًا |
| سير العمل | بطاقة لكل منشور واختصارات Enter وCtrl+S وN وP وA وR وT وD وCtrl+Z | واجهة المحرر | مخطط |
| الجماعي | استبدال، حذف، تنبيه، هاشتاغ، رابط، توقيع، تنسيق، تاريخ، إيموجي | محرك العمليات | منفذ جزئيًا |
| الطبقات | نص، وسوم، روابط، هوية | `editor_engine.py` | منفذ محليًا |
| القواعد | كشف عدم مطابقة قالب القناة | مدقق القواعد | قيد التنفيذ |
| القوالب | خبر، إعلان، مراجعة، ومتغيرات المحتوى القديم | `editor_engine.py` | منفذ محليًا |
| المقارنة | تكرار، تشابه، نقص، اختلاف عنوان أو رابط أو صورة | محرك المقارنة | قيد التنفيذ |
| المختبر | معاينة Telegram، الهاتف، الوسائط، الترتيب، المسودة | مختبر المنشور | مخطط |
| الأمان | حزمة تغييرات، تنفيذ فوري/دفعات/مجدول، إلغاء، أخطاء، تراجع | `change_manager.py` | منفذ محليًا |
| البحث | استعلامات عربية طبيعية مع قناة وفترة ومحتوى ووسائط وروابط | محلل الاستعلام | قيد التنفيذ |
| الجودة | روابط مكسورة ومكررة، أخطاء إملائية، وسوم، قصر، صور وملفات مفقودة، تواريخ وأرقام، أزرار | مدقق المحتوى | قيد التنفيذ |
| العمليات | تنظيف، أرشيف، تجهيز إعادة نشر، وتطبيق على مجموعة | `editor_engine.py` | منفذ للمعاينة |
| الإحصاءات | العناوين، الساعات، الكلمات، التكرار، النص/الوسائط، المشاهدة/التفاعل | لوحة القرار التحريري | مخطط |
| الجمهور | مشتركون، أعضاء، مشرفون، نشاط قابل للرصد | `audience_analytics.py` | منفذ محليًا |
| الجمهور | مؤشر التعليقات×5 والردود×4 والاستطلاعات×3 والتفاعلات×2 والمشاركة والحضور | `audience_analytics.py` | منفذ |
| الجمهور | ملف موحد وتقاطع القنوات والشرائح وتاريخ الجمهور | `audience_analytics.py` | منفذ أوليًا |
| التصدير | CSV وExcel وJSON وPDF وHTML وحماية الملفات | مركز التصدير | مخطط |
| الخصوصية | لا مشاهدي المنشور المجهولين ولا تجاوز لقيود Telegram | `audience_analytics.py` + `SOURCES_AR.md` | منفذ |
| لوحة الجمهور | شرائح، نشاط قابل للرصد، حالة snapshots وملاحظة الخصوصية | `ui/index.html` + `ui/app.js` | منفذ أوليًا |
| تاريخ الجمهور | تسجيل snapshots محلية منذ تشغيل البرنامج | `studio_store.py` | منفذ |
| مزامنة الأعضاء | استخراج الأعضاء المسموحين فقط بعد فحص الصلاحيات | `telegram_gateway.py` + `audience_sync.py` | منفذ ومختبر دون حساب حقيقي |
| فروقات الجمهور | جدد، غادروا، عائدون بين اللقطات | `audience_sync.py` + `studio_store.py` | منفذ |
| اللغة | عربية كاملة، RTL، شرح لكل زر ورسالة واضحة | كل الواجهة | قيد التنفيذ |
| التشغيل | محلي، SQLite، ملفات محلية مشفرة، بلا خادم خارجي | بنية التشغيل | منفذ جزئيًا |
