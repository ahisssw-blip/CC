# مصادر المواصفات والقيود

المصدر الأساسي لمتطلبات المنتج هو ملف المستخدم:

- https://github.com/ahissaw-cloud/ubdate/blob/main/bb.txt
- النسخة الخام: https://raw.githubusercontent.com/ahissaw-cloud/ubdate/main/bb.txt

يتضمن المصدر وظائف إدارة المنشورات، التحرير الجماعي، المحرر الطبقي، القوالب، مقارنة القنوات، مختبر المنشور، الحزم والجدولة، التدقيق، الإحصاءات، الجمهور، تقاطع القنوات، snapshots، واكتشاف الحملات.

## قاعدة الخصوصية

لا ينسب التطبيق المشاهدات المجهولة إلى أشخاص. تُعرض أسماء الأعضاء أو المتفاعلين فقط عندما يتيحها Telegram API والصلاحيات المناسبة، مع إبقاء البيانات محلية وعدم توفير إرسال جماعي مزعج أو تجاوز قيود Telegram.

## مؤشرات النشاط المذكورة في المواصفات

مؤشر العضو القابل للرصد يعتمد على التعليقات × 5، الردود × 4، الاستطلاعات × 3، التفاعلات المعروفة × 2، المشاركات أو إعادة التوجيه، والحضور المتكرر في النقاشات. المشاهدات تُستخدم لتقييم المنشور لا لتحديد مشاهدي المنشور.
