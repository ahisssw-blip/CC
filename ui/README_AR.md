# واجهة استوديو تلغرام العربية

هذه هي طبقة الواجهة العربية RTL. تحتوي حاليًا على الهيكل البصري والتفاعلات الأولية فقط، وتستخدم بيانات تجريبية إلى أن تُربط بخدمة Python وSQLite وTelethon.

## قواعد ثابتة

- كل النصوص الظاهرة للمستخدم بالعربية.
- كل زر يحمل شرحًا عبر `data-tooltip`.
- لا تُنفذ العمليات الخطرة مباشرة؛ الواجهة تضعها في حزمة مراجعة.
- الواجهة لا تحتوي على أي بيانات اعتماد أو جلسة Telegram.

## الربط القادم

تُستبدل البيانات التجريبية في `app.js` بطلبات إلى خدمة محلية آمنة. لا يجب أن يتصل المتصفح مباشرةً بـ Telegram أو أن يرى `API_HASH` أو ملف الجلسة.
